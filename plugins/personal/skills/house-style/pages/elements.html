Managing tasks as plain files

Taskdn is a system for managing tasks and projects as plain markdown files. It includes a desktop app, a CLI and an Obsidian plugin, among other things.

Why bother

Because files outlive apps. You can search them with anything, keep them in git, and read them in twenty years.

  • One file per task
  • Frontmatter for the structured bits
    • Status, dates, project
    • Anything else you like
  1. Install the CLI
  2. Point it at a folder

Remember that your major characteristic as a human being is to work with others.
