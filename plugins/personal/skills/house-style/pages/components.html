Components

Small, optional pieces built on the tokens. Each lives in its own file in css/components/, so copy only what a project needs, change it freely, or use these as a reference and write your own. Open "Markup" under a demo to see its HTML.

Icons on this page are drawn with <use href="#i-…"> from a sprite that page.js injects. In a project, paste the icon's paths straight into the <svg class="icon">, as the examples do.

Forms and controls

Field and input group field.css

A field is a label, control, help text and error as one unit. The error shows once the control has been touched and fails the browser's own validation, or when aria-invalid="true" is set for an error from a server. An input group adds an icon in front, a button after, or both.

Type something that isn't an email and tab away to see the error. That doesn't look like an email address.

Segmented control segmented.css

A few mutually exclusive options that are all worth seeing at once. Real radios, so it works in forms and with the keyboard.

Menu menu.css

A list of actions in a popover, anchored to the button that opens it.

Tooltip tooltip.css

Add data-tooltip to any element. Text only, shown on hover and keyboard focus. Keep the aria-label: screen readers don't reliably read the tooltip.

Tabs tabs.css

The underline slides to the selected tab. Moving aria-selected is up to your script.
